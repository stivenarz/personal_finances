🔥 Crear tu Base de Datos Firebase

Guía paso a paso para conectar la app con tu propia instancia de Firebase

1

Ir a Firebase

Abre firebase.google.com en tu navegador

  1. Haz clic en Ir a la consola
  2. Si no tienes una cuenta de Google, crea una
  3. Inicia sesión con tu cuenta
2

Crear Nuevo Proyecto

  1. Haz clic en Agregar proyecto
  2. Dale un nombre (ej: "Mis Finanzas")
  3. Desmarca "Habilitar Google Analytics" (opcional)
  4. Haz clic en Crear proyecto

⏳ Espera a que se cree (1-2 minutos)

3

Ir a Firestore Database

  1. En la consola de Firebase, en el menú izquierdo, haz clic en Firestore Database
  2. Haz clic en Crear base de datos
  3. Selecciona: Iniciar en modo de prueba
  4. Elige la región más cercana a ti
  5. Haz clic en Crear
⚠️ Modo de prueba: Permite que cualquiera lea/escriba. Lo cambiaremos después.
4

Obtener tu API Key

  1. En la consola, haz clic en el ícono de ⚙️ (Configuración) arriba a la izquierda
  2. Selecciona Configuración del proyecto
  3. Ve a la pestaña General
  4. Baja hasta Tu app web
  5. Si no ves nada, haz clic en Agregar app
  6. Selecciona Web
5

Copiar tu API Key

Después de agregar la app, verás un código JavaScript como este:

const firebaseConfig = {
  apiKey: "AIzaSyD... ← COPIA ESTE",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."
};

🔑 Tu API Key está en la línea que dice apiKey

⚠️ No compartas esta API Key públicamente (ej: en GitHub)

6

Habilitar Authentication Anónima

  1. En la consola de Firebase, en el menú izquierdo, haz clic en Authentication
  2. Haz clic en Comenzar o Get started
  3. Selecciona Anónima como método de autenticación
  4. Activa el interruptor
  5. Haz clic en Guardar
✅ Authentication está listo para que tu app funcione
7

Configurar Reglas de Seguridad (Importante)

  1. En Firestore Database, ve a la pestaña Reglas
  2. Reemplaza el código con esto:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth.uid == userId;
    }
  }
}
  1. Haz clic en Publicar
✅ Ahora solo cada usuario puede ver sus propios datos
8

Configurar la App

  1. Abre la app
  2. Ve a Configuración
  3. En la sección 🔥 Configuración Firebase
  4. Ingresa todos los valores de tu proyecto Firebase:
    • API Key
    • Project ID
    • Auth Domain
    • Storage Bucket
    • Messaging Sender ID
    • App ID
  5. Haz clic en Guardar Configuración
  6. Haz clic en Probar Conexión
✅ Si ves "Conexión exitosa", ¡todo funciona!
Ir a Firebase

💡 Tip: Puedes cambiar tu API Key en cualquier momento desde Configuración
